# 🔥 용접기호 마스터 — 화살표 쪽인가, 반대쪽인가

**기계제도 Ⅴ. 산업 설비 제도하기 — 1. 용접 이음 제도하기 (KS B 0052)** 단원용 학습·수업 보조 도구입니다.
설치 없이 브라우저에서 바로 실행되며, HTML 파일 하나로 오프라인·휴대폰에서도 작동합니다.

## 왜 만들었나

용접기호에서 학생이 틀리는 지점은 사실상 **딱 하나**입니다 — **실선에 붙었나, 파선에 붙었나.**
기호 모양을 다 외워도 이걸 놓치면 반대쪽을 용접합니다.

그래서 이 도구의 중심은 배우기 ②쪽입니다. **화살표 쪽 / 반대쪽 / 양쪽** 버튼을 누르면
왼쪽 기호가 실선↔파선으로 옮겨 가고, **오른쪽 T 이음 단면에서 주황색 용접부가 실제로 반대 구석으로 이동**합니다.

## 구성

| 모드 | 내용 |
|------|------|
| 📖 **배우기** (4쪽) | ① 설명선 구조(부품을 누르면 빨갛게 표시) ② **실선/파선 ↔ 실제 단면 연동** ③ 기본 기호 9종 + 이음 단면 ④ 보조기호·치수 9가지 예 |
| **도전 ①** 어느 쪽? | 기호 그림을 보고 화살표 쪽 / 반대쪽 / 양쪽 판별 (+ 일주·현장 용접) |
| **도전 ②** 기호 이름 | 기본 기호 9종 · 보조기호 이름 맞히기 |
| **도전 ③** 치수 읽기 | `z6 3×50(100)` · `a4` · `d8` 해독 |
| 🎯 **종합시험** | 전 유형을 섞어 10문항 후 **결과 제출** |

## 수록 범위

**기본 기호 9종** — I형(평행) 맞대기 · V형 맞대기 · 일면 개선형(베벨) 맞대기 · U형 맞대기 · J형 맞대기 · 필릿 · 플러그(슬롯) · 점 용접 · 이면 용접

**보조기호 3종** — 평면(동일 평면으로 다듬질) · 볼록형 · 오목형
**특수 표시** — 일주 용접(○) · 현장 용접(깃발) · 꼬리

**치수 문자**

| 문자 | 뜻 | 적는 자리 |
|------|-----|-----------|
| `z` | 필릿 각장 (단면 최대 이등변삼각형의 **변**) | 기호 왼쪽 |
| `a` | 필릿 목두께 (그 삼각형의 **높이**) | 기호 왼쪽 |
| `s` | 맞대기 용접의 용입 깊이 | 기호 왼쪽 |
| `l` / `n` / `(e)` | 용접 길이 / 개수 / 간격(피치) | 기호 오른쪽 |
| `d` | 점·플러그 용접의 지름 | 기호 왼쪽 |

> 교과서 표에는 심 용접·표면 용접·가장자리 용접 등도 있지만, **기호 모양을 확실히 확인한 것만** 수록했습니다.
> 수업에서 더 필요하면 교과서 표 Ⅴ-1을 함께 보여 주세요.

> **선생님께 참고**: 이 도구는 교과서·기능사 관례대로 **KS B 0052의 실선/파선 2줄 방식**(ISO 2553의 system A)만 가르칩니다.
> ISO 2553:2019는 기준선 1줄만 쓰는 방식(system B)도 허용하지만, 학생에게는 혼동이 되므로 넣지 않았습니다.

## 수업에서 쓰는 법

- **수업 자료**: `배우기 ②`에서 버튼을 번갈아 누르며 "기호가 위로 갔을 뿐인데 용접 자리가 반대가 됐지?"를 짚어 주세요. 이 한 장면이 이 단원의 전부입니다.
